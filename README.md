# Finanzas RPG - Update Configuration

Este repositorio contiene únicamente la configuración de versiones para el sistema de actualizaciones automáticas de la app **Finanzas RPG**.

## 📄 Contenido

- `version.json`: Archivo de configuración que la app consulta para verificar actualizaciones disponibles.

## 🔒 Seguridad

Este repositorio es **público intencionalmente** y NO contiene código fuente ni información sensible.

Solo contiene:
- Número de versión pública
- Enlaces a las tiendas oficiales (Play Store / App Store)
- Notas de la versión

## 🚀 Uso

La app consulta automáticamente este archivo para notificar a los usuarios cuando hay actualizaciones disponibles.

**URL del archivo:**
```
https://raw.githubusercontent.com/mauri01/finanzas_rpg_updates/main/version.json
```
